# 心理健康管理系统 - 启动指南

## 📋 项目概述

这是一个专为心理咨询平台打造的管理系统，提供用户管理、论坛帖子审核、数据统计等功能。

## 🛠️ 技术栈

- **前端**: Vue 3 + TypeScript + Element Plus + Vite
- **后端**: Spring Boot + MyBatis-Plus + MySQL + JWT
- **开发工具**: VS Code + IntelliJ IDEA

## 🚀 快速启动

### 1. 环境准备

确保已安装以下软件：
- Node.js 16+
- Java 17+
- MySQL 8.0+
- Git

### 2. 数据库配置

1. 创建数据库：
```sql
CREATE DATABASE mental_health CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. 执行初始化脚本：
```bash
# 在MySQL中执行
source 代码/xinli/src/main/resources/sql/init_database.sql
```

3. 修改数据库连接配置：
```yaml
# 代码/xinli/src/main/resources/application.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mental_health?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: your_username
    password: your_password
```

### 3. 启动后端服务

```bash
cd 代码/xinli
./mvnw spring-boot:run
```

后端服务将在 `http://localhost:8080` 启动

### 4. 启动前端管理系统

```bash
cd 代码/art-design-pro
npm install
npm run dev
```

管理系统将在 `http://localhost:3006` 启动

### 5. 启动用户端

```bash
cd 代码/basic
npm install
npm run dev
```

用户端将在 `http://localhost:5173` 启动

## 📊 API接口说明

### 管理员接口
- `POST /api/admin/auth/login` - 管理员登录
- `GET /api/admin/auth/me` - 获取当前管理员信息
- `GET /api/admin/dashboard/stats` - 获取仪表板统计
- `GET /api/admin/users` - 获取用户列表
- `GET /api/admin/posts` - 获取帖子列表

### 用户接口
- `POST /api/user/auth/register` - 用户注册
- `POST /api/user/auth/login` - 用户登录
- `GET /api/user/forum/posts` - 获取论坛帖子
- `POST /api/user/forum/posts` - 发布帖子

## 🐛 常见问题

### 1. 数据库连接失败
- 检查MySQL服务是否启动
- 确认数据库用户名密码正确
- 检查数据库是否已创建

### 2. 前端启动失败
- 确保Node.js版本 >= 16
- 删除 `node_modules` 重新安装依赖
- 检查端口是否被占用

### 3. API请求失败
- 确认后端服务已启动
- 检查CORS配置
- 查看浏览器控制台错误信息

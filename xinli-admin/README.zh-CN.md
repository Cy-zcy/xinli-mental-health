## 关于心理健康管理系统

这是一个专为心理咨询平台打造的专业心理健康管理系统。系统提供用户管理、论坛帖子审核、心理咨询记录管理和系统数据分析等全面的管理功能。基于 Vue 3、TypeScript 和 Element Plus 构建，为心理健康服务提供者提供现代化、用户友好的管理界面。

## 特点

- 使用最新技术栈

## 技术栈

- 开发框架：Vue3、TypeScript、Vite、Element-Plus

## 安装运行

```bash
# 安装依赖
pnpm install

# 如果 pnpm install 安装失败，尝试使用下面的命令安装依赖
pnpm install --ignore-scripts

# 本地开发环境启动
pnpm dev

# 生产环境打包
pnpm build
```
